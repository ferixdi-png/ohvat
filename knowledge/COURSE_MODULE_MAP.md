# Карта курса Ferixdi AI для голосового наставника

Источник структуры: `ferixdi-png/ferixdi-ai-academy/assets/js/app.js`.

В текущей версии интерфейса исходного курса обнаружено **16 модулей и 131 записей уроков/практик**. Это карта навигации, не утверждение, что полный текст каждого урока уже импортирован в этот репозиторий. Для точного ответа наставник должен открывать соответствующий источник или отдельный файл знаний.
