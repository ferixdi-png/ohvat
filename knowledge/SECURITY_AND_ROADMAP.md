# Безопасность и план переноса базы знаний

## Важное
Репозиторий `ferixdi-png/ohvat` может быть публичным. До загрузки приватных материалов проверь Visibility в GitHub. Не коммить API-ключи, токены, персональные данные, закрытые записи учеников или материалы, которыми нельзя делиться публично.

## План полного переноса
- [ ] Проверить видимость нового репозитория и наличие лицензий/ограничений на материалы.
- [ ] Составить полный список файлов исходного репозитория академии.
- [ ] Перенести текстовые промпты с сохранением исходных имён и версий.
- [ ] Перенести уроки в `knowledge/course/` с метаданными: модуль, урок, исходный URL/путь, дата проверки.
- [ ] Извлечь текст из PDF и приложить конспект с указанием страниц.
- [ ] Разобрать скриншоты интерфейсов и снабдить их датой/названием инструмента.
- [ ] Видео транскрибировать/разобрать отдельно; не считать наличие ссылки полноценным импортом.
- [ ] Добавить индекс для retrieval.
- [ ] Проверить факты по текущим официальным документам Google и OpenAI.
- [ ] Провести тесты на выдуманные ответы, инъекции в документы, утечку системного промпта и обход авторизации.

## Приватность
Для production-сервиса закрытые уроки предпочтительно хранить в приватном хранилище/БД, доступном только backend. Публичный репозиторий должен содержать только код и материалы, разрешённые к публикации. Не считать «пароль» в HTML настоящей защитой.

## Текущее состояние
Первый commit содержит стартовую методику, системный промпт и спецификацию. Это не полный зеркальный импорт исходной академии. Следующая итерация — автоматизировать перечисление и перенос исходных текстовых файлов, а затем отдельно обработать документы и видео.
