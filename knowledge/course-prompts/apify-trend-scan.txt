Как парсить AI-ролики и находить то, что начинает залетать

Для этого удобно использовать Apify. Там уже есть готовые Scraper'ы для TikTok, Instagram и YouTube, поэтому код писать не обязательно.

Сам Apify:
https://apify.com/

На бесплатном тарифе дают стартовый баланс для тестирования парсинга.

1. TikTok

В Apify ищем:
TikTok Scraper
TikTok Hashtag Scraper

Для начала достаточно двух запросов:
#ai
#ии

На каждый можно собирать, например, 500–1000 последних роликов.

Scraper обычно вытаскивает:
* ссылку;
* дату публикации;
* просмотры;
* лайки;
* комментарии;
* репосты;
* длительность;
* автора;
* описание.

2. Instagram Reels

В Apify ищем:
Instagram Scraper
Instagram Reels Scraper
Instagram Hashtag Scraper

Используем те же запросы:
#ai
#ии

Собираем по 500–1000 Reels на каждый хештег.

3. YouTube Shorts

В Apify ищем:
YouTube Scraper
YouTube Shorts Scraper

Запросы:
#ai
#ии

На YouTube можно также просто искать:
AI
ИИ

4. Выгружаем результат

После парсинга:
Dataset → Export

Скачиваем в:
CSV / XLSX / JSON

Для анализа удобнее всего CSV или XLSX.

Желательно сохранить:
URL
Video ID
Date
Views
Likes
Comments
Shares
Duration
Author

5. Загружаем файл в GPT

Прикрепляем результат и пишем:

«Проанализируй этот датасет с видео. Мне нужны не просто ролики с максимальным количеством просмотров, а свежие видео, которые сейчас быстрее остальных набирают просмотры.

Рассчитай возраст каждого видео с момента публикации и приблизительную скорость набора просмотров.

Выдай ТОП-30 самых быстрорастущих видео.

Для каждого укажи:
* ссылку;
* дату публикации;
* возраст видео;
* просмотры;
* просмотры в час;
* лайки;
* комментарии;
* репосты;
* длительность;
* автора.

Отдельно покажи свежие видео, которые сильно выбиваются по просмотрам относительно своего возраста.

Если нужны короткие ролики, оставь только видео до 10 секунд».

6. Как точнее понять, что реально растёт сейчас

Лучше делать два парсинга одной и той же выборки с интервалом в несколько часов.

Например:
12:00 → 80 000 просмотров
16:00 → 200 000 просмотров

Значит ролик набрал:
+120 000 просмотров за 4 часа

То есть примерно:
30 000 просмотров в час

Так намного точнее видно, что реально разгоняется прямо сейчас.

Можно делать одинаковую схему сразу по:
TikTok + Instagram Reels + YouTube Shorts

И для всех площадок использовать только два широких запроса:
#ai
#ии
