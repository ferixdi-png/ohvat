## Важное ограничение
Некоторые большие файлы исходного репозитория превышают объём, который удаётся получить за один ответ инструмента GitHub. Их импортированные копии могут быть неполными. Для таких файлов исходный репозиторий остаётся источником истины, пока файлы не перенесены и не сверены по полному содержимому. Не использовать потенциально усечённые копии как окончательную версию мастер-промпта.
